# SISTEMA DE VENTAS Y COMPRAS PARA GESTION DE DISTRIBUIDORA
## DESCRIPCION DEL PROYECTO
Este sistema es un proyecto desarrollado durante el segundo año (tercer semestre) de Ingeniería de Sistemas en la UNI. Su propósito principal es digitalizar y optimizar la gestión operativa de las distribuidoras, eliminando los riesgos asociados al manejo manual de la información, como la pérdida de datos y las inconsistencias en el inventario.

A través de una base de datos robusta, el sistema garantiza la integridad y seguridad de la información a corto y largo plazo, permitiendo un control estricto sobre:

**Gestión de Inventario:** Control preciso de existencias en almacén.

**Flujo Comercial:** Manejo digital de ventas y compras para evitar discrepancias.

**Control de Entidades:** Registro detallado y seguimiento de clientes, proveedores y empleados.

## TECNOLOGIAS

**LENGUAJE:** C#

**BASE DE DATOS:** SQL SERVER ALOJADO EN LA NUBE AZURE

**INTERFAZ GRAFICA:** AVALONIA UI ARQUITECTURA MVVM

**ARQUITECTURA:** Separación clara entre la interfaz de usuario, la lógica de negocio y el acceso a datos.
